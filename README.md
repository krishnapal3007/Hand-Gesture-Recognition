# ✋ Hand Gesture Recognition using Support Vector Machine (SVM)

## 📌 Overview
This project develops a Hand Gesture Recognition model using the Support Vector Machine (SVM) algorithm. The model classifies different hand gestures from image data, enabling gesture-based human-computer interaction.

This project was completed as **Task-04** of the **Prodigy InfoTech Machine Learning Internship**.

---

## 🚀 Features
- Image preprocessing using OpenCV
- Image resizing (64 × 64)
- Feature extraction
- Train-Test Split
- Hand Gesture Classification
- Model Evaluation
- New Image Prediction
- Model Saving using Joblib

---

## 🛠️ Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

---

## 📂 Dataset
**LeapGestRecog Dataset (Kaggle)**

https://www.kaggle.com/datasets/gti-upm/leapgestrecog

---

## 📊 Machine Learning Model
- Algorithm: Linear Support Vector Classifier (LinearSVC)
- Type: Supervised Learning

---

## 📈 Results

- **Accuracy:** 99.33%

The trained model successfully classified 10 different hand gestures with excellent accuracy.
